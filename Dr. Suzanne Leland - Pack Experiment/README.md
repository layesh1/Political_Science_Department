# Dr. Suzanne Leland — Pack Experiment

## Data
`Pack_Exp.csv` — experimental survey data (N = 1,050).

## Variables
**Independent variables (Treatment 1 only):**
- `race_cat` — race/ethnicity (all categories)
- `politicalparty` — political party affiliation (all categories)
- `white_1` — dummy: White = 1, all others = 0
- `Republican_1` — dummy: Republican = 1, all others = 0

**Outcome variables (treat1):**
- `outcome1_1` — How much do you credit the **contractor**? (1–5)
- `outcome1_2` — How much do you credit the **employer**? (1–5)
- `outcome2` — How **deserving** is Mr. Pack of the employee reward? (1–5)
